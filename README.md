# 汽车维修工单报价软件使用说明
**客户专属定制版：北京田丰汽车修理有限责任公司**

本软件已针对您的最新业务需求完成全面重构升级：
1. **维修单号置顶**：打开页面自动生成单号并醒目置于顶部（标签不带“置顶”字样），也可点击「重新生成」或手动修改；
2. **电脑 / 手机自适应**：电脑端为宽屏工作台；手机端顶部按钮自动换行、表单自动变为单列、新增项目通过弹窗填写、明细表列宽固定并可左右滑动，工时/数量按钮加大，方便触屏操作；
3. **车辆基础信息完善**：
   - 新增 **车架号 (VIN)** 录入项（非必填）；
   - **车辆颜色** 改为支持「下拉快速选择常用色 + 自由键盘输入修改」；
   - 彻底移除了 **报价人** 字段；
4. **项目明细**：
   - 列顺序为「序号 → 项目/配件名称 → 车型 → 工时 → 单价 → 数量 → 单位 → 工时费 → 小计」；
   - 点击「+ 添加项目」会弹出填写窗口，不再需要横向滑动表格录入；
   - 明细区右侧可设置全局 **工时费（元/工时）**，每行工时费 = 工时 × 全局工时费；
   - 每行小计 = 单价 × 数量 + 工时费，总额自动累加；
   - **工时** 列提供上下调整按钮，每次加减 0.5 工时；
5. **正式抬头与输出规范**：
   - 默认公司抬头为 **北京田丰汽车修理有限责任公司**，顶部抬头不显示地址与服务电话；
   - 公司抬头下方居中显示加粗标题 **「结算单」**，标题下方不再有横线；
   - A4 打印时自动输出：维修单号、结算日期、车辆信息、车型/工时明细、工时费；
   - 明细总计行显示「总计 / 金额（大写）/ 数字总额」；
   - 结算区只保留「欠款金额 / 实收金额」一行，下方附注说明文字；
   - 底部为地址（北京市丰台区大瓦窑782号）、制单人（管理员）、电话（13810979552）、客户签字，不使用边框栏目；
   - 未填写的内容在打印时直接留空，不使用横杠占位。

## 🚀 启动方式

* 双击文件夹中的 **`双击直接运行.bat`** 或 **`index.html`**；
* 软件将在系统默认浏览器中瞬间打开，全离线可用。

## 🛠️ 字段与功能一览

| 模块 | 核心功能与字段 | 说明 |
| :--- | :--- | :--- |
| **维修单号** | 维修单号 | 格式如 `WX-20261123-001`，支持一键点击「重新生成」或手动输入 |
| **车辆档案** | 车牌号码 | 拆分为「省份简称下拉选择 + 车牌号码输入」两部分，字母自动转为大写，自动组合为完整车牌 |
| | 车型型号 | 输入后**自动联动下方所有明细行的车型列**（例如：`宝马 530Li 豪华版`） |
| | 车架号 (VIN) | 17位车辆车架号输入框 |
| | 车身颜色 | 下拉列表支持秒选矿石白、珍珠白、极夜黑、银灰、中国红等，同时文本框支持键盘任意改写 |
| | 进厂/结算日期 | 进厂日期自动预填当天，结算日期自动预填次日，点击日历可修改 |
| | 里程与车主 | 行驶里程 (km)、车主姓名、联系电话 |
| **明细表格** | 添加项目 | 点击「+ 添加项目」弹出填写窗口，录入名称、车型、单位、工时、单价、数量后确认添加；弹窗内工时每次步进 0.5，数量每次步进 1 |
| | 全局工时费 | 明细区右侧设置 1 工时价格，所有条目按工时自动计算工时费 |
| | 序号 | 每行自动编号 |
| | 项目 / 配件名称 | 紧跟序号列，纯手动输入，无下拉联想；输入框为纯白无提示 |
| | 车型 | 自动继承上方车型，亦支持针对该项单独修改 |
| | 工时 | 提供上下调整按钮，每次加减 `0.5` 工时，也可手动输入 |
| | 数量 | 提供上下调整按钮，每次加减 `1`，也可手动输入；新建行默认 1 |
| | 单价 / 单位 | 新建行默认留空，由用户按需填写 |
| | 工时费 (元) | `工时 × 全局工时费`，随工时或全局工时费自动变化 |
| | 小计 (元) | `单价 × 数量 + 工时费` 自动联动计算 |
| | 排序与管理 | 每行支持上移、下移调整打印顺序，支持一键删除 |
| **金额汇总** | 财务级自动换算 | 实时计算全单总额（含工时费），打印时大写金额显示在总计行（如：`壹仟贰佰捌拾元整`） |
| **打印输出** | PDF 预览 | 点击顶部「PDF 预览」可在页面内查看 A4 版式，预览窗口内可直接「打印 / 保存 PDF」 |
| | 打印 / 另存为 PDF | 点击即可呼出打印面板，已适配 A4 纵向排版，在打印机目标中选择「另存为 PDF」即可保存文件；公司抬头之上无任何内容 |
| | 微信分享 | 浏览器无法直接调用微信发送本地 PDF；请先在预览中保存 PDF，再到微信中发送文件 |
